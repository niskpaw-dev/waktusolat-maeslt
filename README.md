Web app waktu solat Masjid Al Ehsan Kampung Sungai Lang Tengah (Kuala Langat).
Single-file HTML, tiada build. Live: https://waktusolat-maeslt.vercel.app

- Data: [API waktu solat](https://apiwaktusolatsgr03.vercel.app/api/waktu-solat) (2026: JAKIM e-Solat · 2027: Takwim Mufti Selangor, Daerah Kuala Langat)
- Identiti masjid (nama, logo, akaun infaq) diubah dalam objek `MASJID` di bahagian atas `<script>`.
